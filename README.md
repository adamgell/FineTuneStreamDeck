# FineTune for Stream Deck

An installable macOS plugin for FineTune's versioned local automation API. It supplies app volume/mute/boost, routing, device/input controls, EQ, AutoEQ, loudness, management, popup controls, scenes, and a typed FineTune Command action for the complete API catalog.

## Install

1. Quit stock FineTune and launch the custom **FineTune Automation** build. Keep one audio controller running.
2. Grant that app system audio access when needed for actual per-app audio control. Unit tests and the plugin's API connection require no audio recording permission themselves.
3. In FineTune, enable **Settings → General → Local Automation API**.
4. Open the supplied `.streamDeckPlugin` package. Import `finetune-xl.streamDeckProfile` for the 32-key Stream Deck XL layout.
5. Select a Music button in Stream Deck and choose its shared Music target, then Save. Its volume, mute, and boost buttons share that target. Repeat for Browser, Call, Speakers, Headset, Microphone, and EQ App as needed.

Use the supplied configuration screens to select routes, correction profiles, preferences, presets, or scene commands. No URL or shell-script buttons are needed. Saved targets remain selected when unavailable and become usable again on reconnection.

## Compatibility and status

macOS 15.4+, Stream Deck 7.1+, Node 24 plugin runtime, FineTune automation API v1. Initial software acceptance target is Stream Deck 7.6.0 and hardware target is XL. Keys are supported; compatible numeric actions also expose dial/push/touch controls on dial-equipped models, with physical dial testing recorded separately.

The plugin displays offline, configure, unavailable, pending, and error states. It uses authoritative snapshots. Lost toggles/steps are not replayed. Scene results can be partial; they are not transactions.

The complete custom FineTune branch works independently of upstream PR acceptance. Stock builds without the API cannot supply these plugin controls. See the custom build and rollback guide alongside the app.

## Development

```sh
npm ci
npm test
npm run typecheck
npm run build
npm run validate
npm run pack
```

Resources and the XL profile are generated by `python3 scripts/resources.py`. The profile contains only this plugin's actions and placeholder shared targets; it does not modify installed profiles. `npm run pack` writes the installable package under `dist/`.

API source and upstream contribution are maintained separately. Protocol and catalog fixtures are synthetic; no personal app activity or device identifiers are included.
